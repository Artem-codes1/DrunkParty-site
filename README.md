# DrunkParty — коммерческий шаблон

Портфолио-готовый Static Site для nightlife-событий. Проект использует HTML, CSS и нативный JavaScript без фреймворков и сборщика.

## Что включено

- Адаптивная пэжа с атмосферным дизайном.
- Программа вечера, lineup, афиша, галерея и статистика.
- Три уровня билетов с демо-платежом.
- FAQ с несколькими ответами.
- Счётчик до события, меню, анимации и модальное окно.
- Восьми адаптивных локальных SVG-иллюстраций.
- Поддержка prefers-reduced-motion и keyboard navigation.

## Запуск

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`.

## Замена контента

- Названия мероприятий, адреса, даты и цены: `index.html`;
- Изображения: `assets/`;
- Ссылки Telegram и социальных сетей: `index.html` и `script.js`;
- Реальные обработчики заказа: `script.js`.

Платежи и реальные внешние службы не подключены. Кнопки заказа открывают демонстрационное окно.

## Файлы

- `index.html` — структура и контент;
- `style.css` — визуальная система и адаптация;
- `script.js` — меню, FAQ, счётчик, модальное окно и уведомления;
- `assets/` — локальные SVG-иллюстрации.
